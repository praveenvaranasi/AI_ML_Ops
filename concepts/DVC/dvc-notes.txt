2.  Data set is stored in the S3 Bucket
    Data set metadata is stored in the git repo
        - Commit .dvc/config directory to the git repository (This tells us regarding the remote of the dvc)
        - Commit <file>.csv.dvc file to the git repo. (This contains the checksum of the actual dataset i.e., <filename>.csv)

    Committing process:
        - Added .csv pattern into the .gitignore 
            **/*.csv
        - Added 'concepts/DVC/dataset/diabetes.csv' into the repo
        - Ran dvc init
